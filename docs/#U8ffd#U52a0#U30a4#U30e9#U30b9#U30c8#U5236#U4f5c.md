# 追加イラスト制作（2026-10-16）

既存背景9点を保ったまま、不足している小物と猫の画像を追加する。美咲・拓海の別デザインや、未確定の湊・紗季の顔は生成しない。

## 制作対象

1. CAT_BASE: 壁紙用の猫1匹。30個の独立した配置データへ同じ素材を配置
2. CAT31: 同じ絵柄・姿勢の白猫1匹。31匹目としてだけ使用
3. PROP01: BG03の古いPCを参照した、背景透過のPC本体

30匹を1枚で生成した絵は使用しない。30匹版と31匹版の既存30匹の位置は一致させる。31匹目は最初から画面の隅に配置し、登場アニメーションや発光を付けない。

組み込みimagegenで1素材ずつ生成。生成後に透過alphaと見た目を確認し、assetsに保存する。
