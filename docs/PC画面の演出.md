# PC画面のニューラル背景と文字入力

参照: [Interactive Neural Network Viz / VoXelo](https://codepen.io/VoXelo/pen/EaabxLj)

参照作品の橙色の発光、枝状の接続、光の伝播、緩やかな立体回転を、ゲーム内PC用のCanvas描画で独自実装。元コードの転載やCodePenのiframe埋め込みは行っていない。外部ライブラリ・ネット接続は不要。

オルドの発話と冒頭の警告にのみ背景を表示。猫の壁紙・投票画面・接続終了後・最終節は変更しない。PCの文字は約30〜70msの揺らぎを付け、句読点で溜める。最初に約170ms待ち、短い連続入力と小休止を混ぜる。本文送りのタップは表示途中のPC文字も全文表示し、次のタップで進む。AUTOはPC側の文字完了も待つ。

演出軽減・即時表示設定・既読スキップ時は文字を即時表示。演出軽減ではネットワークは静止画。通常は24fps上限・DPR1.5上限。オルドの画面がない時、ログ・設定・目次の表示中、別タブ表示中は描画停止。退出時は描画と文字タイマーを破棄。

## 検証

既存9テストと、新規5テスト（原文・Unicode保持、古い台詞のタイマー無効化、同じ台詞の途中再開、即時表示、描画規模の制限）が成功。reader.jsの構文チェックも成功。

今回の確認用ローカルサーバーは、制限内で起動するとブラウザーから接続できず、制限外の起動は現在の実行許可設定により拒否された。そのため、この変更後の見た目・実際の入力テンポ・iPhone性能は未確認。確認用ページはtools/pc-preview.html。
