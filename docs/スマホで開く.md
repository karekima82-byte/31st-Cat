# 同じWi-Fiのスマホで開く

1. PCとスマホを同じWi-Fiに接続する。
2. 制作フォルダの `START_SMARTPHONE.cmd` をダブルクリックする。
3. 表示された `Smartphone: http://…:8831/` のURLを、スマホのSafariまたはChromeで開く。
4. 読んでいる間はPCを起動したまま、サーバーの黒いウィンドウも開いておく。終了はCtrl+C。

今回確認できたPCのWi-Fiアドレスは `192.168.2.105` なので、現在のURLは `http://192.168.2.105:8831/`。IPが変わった場合は、起動時に表示されるURLを使う。

Windowsのファイアウォール確認が出た場合は、自宅などの信頼できるプライベートネットワークでのNode.js通信を許可する。こちらからファイアウォール設定は変更しない。

これは同じWi-Fi内での確認用。モバイル回線や別の場所からは開けない。ゲストWi-Fiなど端末同士の通信が禁止された接続では、通常の同じWi-Fiへ切り替える。

セーブはスマホのブラウザー内に保存される。PCでの読書位置とは自動同期しない。本編未接続。

## 今回の検証状況

配信する実ファイル、HEAD応答、配信対象外ファイルの拒否の3テストは成功。制限内でサーバー起動とWi-Fiアドレスの表示までは確認できたが、接続確認は実行環境のソケット通信制限で拒否された。制限内の確認用プロセスは停止済み。現在の許可設定では制限外での起動ができないため、上記起動ファイルをユーザーのPC側で開く必要がある。スマホ実機接続は未確認。
