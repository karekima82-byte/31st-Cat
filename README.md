ユーザー提示のCodePen演出候補は [演出リファレンス](docs/演出リファレンス.md) に保存しています。

## 起動

`node tools/serve.mjs` → http://127.0.0.1:8831 （npmがある環境では `npm start` でも可）

スマホ用は `START_SMARTPHONE.cmd` を開くか、`node tools/serve.mjs --lan` で起動。PCと同じWi-Fiで、表示されたSmartphoneのURLを開きます。詳しくは [スマホで開く](docs/スマホで開く.md)。

「読む」で美咲の推薦会話→全8節の完成稿→読後会話を再生します。「続きから」で段落・ページ位置を復元。「演出プレビュー」は本文とは別の制作確認用です。背景9点はassetsに保存済み。tools/art-preview.htmlで一覧確認できます。

今回のZIP改稿は全8節211段落。本文は手入力せず取り込み、原本とSHA256を保管しています。Markdownの強調記号は表示時だけ解釈し、句読点や台詞は変更しません。BGMと文字送り音は同梱MP3を再生し、初期音量は30%。画面右上の「音 ON/OFF」か設定から変更できます。台詞音声はありません。

操作検証は `/?test=1` で本番の読書記録と分離できます。

オルドのPCには、発光する枝状ネットワークと、緩急のある文字入力を追加しました。`tools/pc-preview.html` で表示だけを確認できます。参照と実装方針はdocs/PC画面の演出.mdに記録しています。

追加イラストとして通常の猫・31匹目の白猫・透過PC本体を生成しました。生成猫2点は比較用として保持。ゲーム内の壁紙は指定のcats_30.jpg / cats_31.jpgを無加工で使用します。PC本体は組み込み前の素材です。`tools/illustration-preview.html` に素材と30匹／31匹の比較があります。生成プロンプトはdocs/追加イラスト_生成プロンプト.mdへ保存。

## 完成稿の取り込み

`node tools/import-manuscript.mjs "完成稿の絶対パス.md"`

原本をsourceへバイト単位で保存し、SHA256と8節の段落をdata/manuscript.jsonへ出力します。小説本文の手入力・補完は行いません。見出し形式の違いで失敗した場合は、原稿を修正せずパーサーを調整してください。取り込み後に「読む」「続きから」が有効になります。

## 本編接続（未実施）

同じオリジンへ本フォルダを配置し、integration/bridge.jsのopenThirtyFirstCatを明示的に呼び出します。src、initialState、onSave、AbortSignalを受け取ります。onSaveで本編の既存セーブへnovel stateを格納し、Promiseの返却後に呼び出し元の場面から再開します。本編の章番号やシーン番号を書き換えません。completedは本文の全段落通読後のみ成立します。制作プレビューでは既読・読了を付けません。

通信は同一オリジン・iframe送信元・セッションIDを検証。本編素材はコピーせず、導入／読後会話は設計書の仮台詞を文字だけで表示しています。正式採用の美咲素材と既存会話UIへの差し替えは接続時の作業です。
